# 依尘の博客 · 前台重设计原型简报

## 0. 你的任务

你是这个中文技术博客前台的视觉设计师。请在**不改变现有页面布局骨架**的前提下，画出重设计后的高保真原型。

设计方向已经定稿：首页用「方案 E 发现层下沉」，其余页面按「批次 1 规格」。你的工作是把规格画出来，不是重新提方案。规格没覆盖的细节，按同类元素已有的样式推断，并在画面旁用一行小字注明你的假设。

请按这个顺序做，每一步做完停下来等我反馈：

1. 设计系统页：亮暗两套色板、字体阶梯、组件样例（导航、面板、卡片、chip、区块标题、按钮、输入框、focus 态）。
2. 首页：桌面 1440 暗色，确认后补亮色和手机 390。
3. 文章列表 `/posts`。
4. 文章详情 `/posts/[slug]`。
5. 分类、标签、系列页。

## 1. 产品与读者

- 站名「依尘の博客」，产品名 Inkforge。它是一个中文技术博客加 AI 内容平台。
- 内容包括文章、系列连载、分类与标签、专题指南、每天自动生成的 AI 日报，以及评论、点赞、收藏、Newsletter 订阅。
- 读者是中文开发者和产品人。桌面端以深度阅读为主，手机端以碎片浏览为主。
- 气质安静、偏冷的蓝青色调。半透明的毛玻璃面板浮在一张顶部背景图上。暗色是默认主题。
- 这是内容优先的阅读站，不是营销落地页。

## 2. 硬约束

- **保留布局骨架。** 导航、栅格、左侧栏、主列区块顺序、页脚都在原位。只改层级、密度、对比度和节奏，以及规格里明确写出的增删。
- 不新增导航项、页面或路由。
- 图标只用 lucide 线性图标，描边 1.5 到 2px。不用 emoji，不用彩色插画图标。
- 正文不小于 15px，行高不小于 1.65。触控目标不小于 44×44px。文字对比度不低于 4.5:1。
- 所有可聚焦元素画出 focus-visible 态：2px accent-sky 实线外框，外扩 2px。
- 圆角、阴影、毛玻璃沿用现值。不要换成新拟态、粗野主义、大面积渐变色块或霓虹风。
- 中文排版：页面级标题用 Noto Serif SC 衬线，其余文字用阿里巴巴普惠体。中英文之间留空格，日期和计数用等宽数字。
- 只用第 3 节的颜色 token，不自造新颜色。

## 3. 设计 token

### 3.1 主题机制

- 颜色用 OKLCH。带 `h` 的颜色共享一个色相变量 `--hue`，默认 224（蓝青）。读者可以在导航里用色相选择器改它，原型按 224 画。
- 暗色是默认主题，亮色可切换。
- hex 是 hue 224 下的近似值。

## 4. 组件样式

- **导航胶囊。** 高 50px，最宽 52rem，在页面顶部居中浮动，全圆角，毛玻璃 `blur(18px) saturate(1.18)`。
  - 亮色底是白色渐变，左上叠一团暖色 16% 光斑、右上叠一团天蓝 13% 光斑，带偏蓝的柔和外阴影。暗色底见 3.3。
  - 三段布局。左边是 28px 圆角方形 logo 加站名（0.92rem 700）。
  - 中间是导航项「首页、文章、系列、归档、关于」，每项是 lucide 图标加 0.8rem 700 文字，高 40px，圆角 8px，hover 底色 sky 10%。
  - 右边：lg 以上是内联搜索框（占位「搜索」）；sm 以上是色相按钮和明暗切换按钮；md 以下换成汉堡按钮，展开为导航下方的浮动面板。
  - 向下滚动时隐藏，向上滚动时出现。
- **背景图层。** 页面顶部铺一张全宽背景图（站点设置里配置的风景或插画），按 3.4 的高度向下渐隐到 page-bg。上面叠一层 72px 网格纹理，透明度 8%，带蒙版淡出。亮色另加 3.2 的叠色。
- **面板。** 1px reader-border 描边，reader-panel 底，圆角 16px，毛玻璃 `blur(20px) saturate(1.04)`，常态阴影。
- **卡片。** 同面板，圆角 24px。hover 时描边换成 border-strong，阴影换成 hover 阴影，上浮 2px，卡内淡入一团 sky 径向光。
- **精选卡。** panel-elevated 底，左上叠 sky 13% 径向光。
- **chip。** 全圆角，0.75rem 600，内边距 .45rem .7rem，文字、底色、描边见 token 表。
- **区块标题。** 1.125rem 700，左侧一根 3px × 18px 的 sky 竖条。
- **图标按钮。** 44px 方形，圆角 10px。
- **卡片尾部箭头列。** 卡片右侧 2.25rem 宽的一列，放 chevron-right。
- **专题头。** 圆角 28px，1px 描边，蓝灰渐变底。
  - 亮色是 135° 渐变 #7599A7 → #A6BCBF → #BC9581，左上叠天蓝光斑，右上叠暖橙光斑，底部渐隐到页面底。
  - 暗色是 #011E28 → #00151C → #3B2116，同样叠两团光斑。
  - 背景上有稀疏星点。
- **页脚。** 一个面板，内含站名 kicker、一句描述、入口 chips（文章、系列、分类、归档、RSS 订阅）。

## 5. 全站骨架（不许改）

- 从上到下依次是：导航胶囊、顶部背景图、居中的内容容器、页脚面板。
- xl 及以上是左侧栏加主列两栏。xl 以下侧栏消失，只剩主列。
- 左侧栏从上到下（本次调序）：
  1. 资料面板（浮动）：头像、站名、一句简介、社交图标。
  2. 热门：3 条，等宽序号 01 到 03。
  3. 分类：前 4 个，名称加篇数，底部「更多分类」。
  4. 标签：10 个 chip 加「全部标签」。
  5. 阅读统计：仅登录态显示，原型里可以省略。
- 文章详情页是三栏：左侧栏、正文、右侧目录栏。

## 6. 首页（方案 E「发现层下沉」）

主列从上到下：Hero 精选卡、AI 日报面板、最新文章列表，以及本次新增的系列与专题面板、发现区（仅 xl 以下）、Newsletter 面板，最后是页脚。前三块的顺序不动。

1. **Hero 层级反转。** 读者第一眼应落在精选文章标题上，而不是站名上。
   - 站名缩成报头，用站名报头尺度。站点描述最多 2 行。
   - 精选文章标题用首页精选尺度，最多 2 行。下方一行 meta：分类 · 日期 · 阅读分钟。按钮文案「阅读全文」。
   - 封面固定 4:3，md 以上在右侧，与文字区等高。手机上文上图下，封面高 12rem。
2. **AI 日报面板分栏。** md 以上左右两栏，比例 2:3。
   - 左栏是今日日报：日期 kicker（等宽）、标题 0.9375rem、摘要最多 3 行、「阅读今日日报 →」链接。
   - 右栏是往期 4 条，每条一行：等宽日期加标题，单行截断，每条高至少 44px。
   - 手机上今日卡在上、往期列表在下，不做横滑。
   - 当天日报还没生成时保留面板，显示「今日日报生成中」。
3. **最新文章列表。** 每条是 4:3 缩略图（桌面宽 9rem，手机宽 6.5rem）、标题、摘要（sm 以上显示，最多 2 行）、meta 行。区块标题带竖条，与日报一致。
4. **真粗体。** 所有 700 的无衬线标题按真 700 字重画，不要画成 500。
5. **亮色模式。** 背景图高度 34vh 并叠色，卡片提亮，正文加深，避免发灰。暗色背景图高度 42vh。
6. **节奏与可达。** 区块间距见 3.4。focus 态见第 2 节。侧栏面板标题统一 0.95rem，热门用等宽序号。
7. **侧栏调序。** 见第 5 节。
