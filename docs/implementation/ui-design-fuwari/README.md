# Inkforge 前后台统一 UI 设计规范（Fuwari × Shiro 温润独立博客与高效工作台）

- 基线分支：`origin/main`（`d095b90`）→ 改造分支 `feat/fuwari-ui-redesign`
- 设计取向：去 AI 模板感、去生硬灰线框套娃、保留“真实人的书房与工作室”温度

## 1. 设计文件目录

1. [01-public-blog-ui.html](./01-public-blog-ui.html) — 前台三大核心视图（首页流、文章沉浸阅读页、按年份时间线归档页 + 实时 `0–360` `--hue` 色相滑块）
2. [02-admin-operations-ui.html](./02-admin-operations-ui.html) — 后台运营工作台（概览看板、高密度文章管理队列、AI 日报候选编发台）
3. [03-admin-editor-workspace-ui.html](./03-admin-editor-workspace-ui.html) — 沉浸式写作与 AI 协同审校工作台（分屏/专注/读者同源预览 + 字段级 AI 提要回填）

## 2. 前后台统一 Token 契约

- **动态色相引擎**：全站共享单一 `--hue`（默认 `215` 夜读蓝灰，支持前台调色盘滑块自定义），主强调色 `--primary: oklch(0.70 0.11 var(--hue))`，柔和交互底色 `--primary-soft: color-mix(in oklab, var(--primary) 15%, var(--card))`。
- **无硬框色阶分层（告别 `1px` 线框堆砌）**：
  - 画布底色（暗 `#10151c` / 亮 `#f2f4f8`）与卡片表面（暗 `#171e28` / 亮 `#fcfcfd`）依靠柔和明度差与极淡顶高光区分，去掉原本层层包裹的灰蓝色粗描边。
  - **前台圆角**：横幅 `18px`、主卡片 `16px`、内嵌配图与按钮 `10–11px`（重现 `saicaca/fuwari` 的内嵌圆角画框感）。
  - **后台圆角**：收敛一档（外框 `13px`、输入框与按钮 `7–9px`），让工具隐入任务，不再与前台割裂成两套异构配色。

## 3. 对应当前 `main` 的关键改造映射

| 模块 | 当前 `main` (`3313ef7`) 痛点 | 新设计稿方案 |
| :--- | :--- | :--- |
| **前台横幅与布局** (`AppShell` / `Navbar`) | 顶部空白留白大、缺少博主在场感，窄屏收起侧栏后变成匿名列表 | 复用 `fuwari-night-city-bg.svg` 做 `182–196px` 氛围横幅，主网格叠入 `-38px`；宽屏左栏展示 `Fuwari` 个人卡（含 `20×4px` 主题短横条），窄屏保留紧凑个人问候条 |
| **AI 日报条** (`HomeAiDailyStrip`) | 5 等分窄列挤压标题断行，像生硬的资讯门户 | 改为 `Shiro` 微动态风格的「早读便签」，支持点击日期原位切换近 4 期简报 |
| **文章卡片流** (`HomeEditorialHero` + `HomeLatestPosts` + `PostCard`) | 首屏巨型站名卡喧宾夺主；列表强塞默认 SVG 封面 | 置顶文章回归统一 `Fuwari` 卡片流：右侧 `28%` 内嵌圆角实景封面、斜杠标签（`#A / #B`）、字数与时长；无图随笔右侧采用 `Fuwari` 竖条进入按钮（`›`） |
| **归档页** (`archives/page.tsx`) | 外层面板套每篇独立卡片，层级冗余 | 改为单张温润卡片内的 `Fuwari` 年份虚线时间轴，悬停圆点亮起 |
| **后台文章管理** (`admin/posts/page.tsx`) | 顶部 5 张彩色大指标卡挤占半屏，表格可视行极少；`<1024px` 侧栏消失无入口 | 砍掉 5 张彩色大卡，合并为单行分段筛选器 + 搜索框，释放 80%+ 视口给高密度无噪音表格；补齐移动端导航抽屉 |
| **写作工作台** (`AdminPostWorkspace` + `MarkdownEditor`) | 预览区使用默认 `prose-zinc` 与线上排版不一致；AI 弹窗阻塞打断 | 右侧预览严格复用前台文章样式；右侧检查器拆分为「AI 协同审校（字段级一键回填）」与「发布与封面」双页签 |
