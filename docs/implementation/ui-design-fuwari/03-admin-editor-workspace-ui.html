上周三早上看监控日志时，发现凌晨四点的定时发布任务报了一次连接池等待超时。

顺着事务边界定位慢调用

翻看发布函数的调用栈才意识到，之前为了保证封面回填的原子性，把外部图片拉取直接写进了同一个交互式事务块里：

const uploadedCover = await ensurePostCoverOutsideTx(draft);
await prisma.$transaction(async (tx) => {
  await tx.post.update({
    where: { id: draft.id },
    data: { published: true, coverImage: uploadedCover }
  });
});

拆开事务后，单次锁连接时间从 4.2 秒降到了 6 毫秒。

建议摘要 (Excerpt)
复盘凌晨定时发布偶发超时的根因：将慢速外部封面拉取剥离交互式事务后，单次锁连接耗时从 4.2s 降至 6ms。
